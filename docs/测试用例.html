使用说明：
  • 「实际结果」与「状态」为可填写字段，支持在线编辑后打印；状态默认值「待测」。
  • 顶部模块筛选器可按模块定位用例；打印按钮支持横向 A4 输出。
  • 状态可选：待测 / 通过 / 失败 / 阻塞 / 不适用。
